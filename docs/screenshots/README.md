# Add local screenshots

This folder intentionally contains no fabricated screenshots. Run the commands locally and capture:

1. `program-output.png`: `run.cmd demo`.
2. `test-results.png`: `run.cmd test`, with the successful checks visible.
3. `plots-results.png`: open `docs/plots/time-vs-n.png` or a readable result table and capture the window.

In Windows, use Win+Shift+S and save the images here. Then uncomment the three screenshot image lines in the main README. Keep text large enough to read and do not include passwords, tokens, or unrelated private information.
